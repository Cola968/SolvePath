Datenschutzerklärung für SnapStudy

SnapStudy ist eine Lern-App für Notizen, Lernrunden, Wiederholungen und geteilte Challenges.

Lokale Daten

Notizen, Zeichnungen, Lernfortschritt und Wiederholungsdaten werden in der aktuellen Beta grundsätzlich lokal auf dem verwendeten Gerät bzw. im lokalen App-/Browser-Speicher abgelegt.

Analyse von Texten und Bildern

Wenn du die Funktion zum Erstellen einer Lernrunde aus Text oder einem Bild nutzt, kann der von dir übermittelte Inhalt an den SnapStudy-Server gesendet werden. Falls eine externe KI-Analyse verfügbar ist, kann dieser Inhalt zur Verarbeitung an den jeweils konfigurierten KI-Dienst weitergegeben werden. Reine Text-Lernrunden können bei einem Ausfall des externen Dienstes teilweise lokal erzeugt werden.

Kamera und Dateien

Die App kann Zugriff auf Kamera oder ausgewählte Dateien anfordern, wenn du selbst ein Bild für eine Lernrunde auswählst. Der Zugriff erfolgt nur für die von dir gestartete Funktion.

Technische Verbindungsdaten

Beim Zugriff auf den Online-Dienst verarbeiten Hosting- und Infrastrukturprovider technisch notwendige Verbindungsdaten, zum Beispiel IP-Adresse, Zeitstempel und Anfrageinformationen, um den Dienst auszuliefern und Fehler zu diagnostizieren.

Keine Werbung und kein Verkauf von Daten

Die aktuelle Beta enthält keine Werbe-SDKs. SnapStudy verkauft keine personenbezogenen Nutzerdaten an Werbetreibende.

Löschen lokaler Daten

Lokale Daten können durch Löschen der App bzw. der Website-Daten auf dem Gerät entfernt werden. Eine spätere Kontofunktion kann zusätzliche Löschmöglichkeiten erfordern; diese Erklärung wird dann aktualisiert.

Kontakt

Für Datenschutzanfragen nutze bitte den im jeweiligen Store-Eintrag hinterlegten Entwicklerkontakt. Vor der öffentlichen Veröffentlichung wird hier zusätzlich eine dauerhafte Kontaktadresse ergänzt.
