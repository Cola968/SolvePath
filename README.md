# SolvePath v0.1

SolvePath hilft bei Mathematik und Physik mit dem nächsten sinnvollen Schritt: Aufgabe → Diagnose → kleiner Hinweis → eigener Lösungsweg → Ergebnisprüfung → Lernprofil.

## Entwicklungsplan

1. Expo Router, TypeScript und ein ruhiges Design-System einrichten.
2. Acht strukturierte Demo-Aufgaben und austauschbare Analyse-Schnittstelle erstellen.
3. Diagnose, Hint Ladder, geführten Lösungsweg und Ergebnisprüfung verbinden.
4. Lokale Speicherung, Lernprofil und Prüfungsmodus ergänzen.
5. Domain-Tests, TypeScript, Lint und Android-Export prüfen.

Weitere Installations- und Architekturhinweise folgen mit der Implementierung.
